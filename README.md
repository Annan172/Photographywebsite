# Photography Website 📸

## Project Description
This project is a photography website created to showcase a collection of favorite
city photographs. The website explores urban life through images and highlights how
photography preserves moments, emotions, and memories over time.

The site was designed and built as part of a web development project, focusing on
correct use of HTML elements, CSS styling, and visual appeal.

---

## Features
- A photography-themed homepage
- A third-person biography of the website creator
- A gallery of favorite city photos
- A custom-made CSS stylesheet
- A separate design page explaining the website layout
- Clean and simple visual design

---

## Technologies Used
- **HTML** – structure and content
- **CSS** – styling and layout
- **GitHub Pages** – website deployment
